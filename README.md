# 停车场管理系统 (park_888)

一个基于 **Java SE** 的命令行停车场管理系统，用于演示面向对象程序设计的基本实践：
车辆进出登记、车位余量查询、停车费结算与收入统计。

项目刻意保持轻量：**无第三方依赖、无构建工具、无数据库**，仅用 `HashMap` 与 `ArrayList`
在内存中维护运行状态，适合作为 Java 课程设计、实验报告或初学 OOP 的参考实现。

## 功能特性

| 编号 | 功能 | 说明 |
| :---: | :--- | :--- |
| 1 | 进入登记 | 校验车牌是否已在场，登记进入时间，占用一个车位 |
| 2 | 驶出结算 | 计算停车费，模拟支付成功后释放车位并计入收入 |
| 3 | 当前车位查询 | 显示剩余可用车位数 |
| 4 | 收入统计 | 累加所有已完成结算的订单金额，输出总收入 |
| 5 | 退出系统 | 结束程序 |

设计要点：

- **状态去重**：同一车牌重复驶入会被拦截，提示"车辆已登记"。
- **支付校验**：只有输入金额与应收金额完全一致才视为支付成功，否则结算失败、车位不释放。
- **一次入场一次结算**：已驶出的车辆再次入场会被视为新车入场（状态位 `state` 支持 0/1 复用）。
- **静态车位池**：`Park.stallCount` 为全局共享的车位计数器，默认总容量 100。

## 快速开始

### 环境要求

- JDK 8 或更高版本

```bash
java -version
javac -version
```

### 编译

在项目根目录执行：

```bash
# Windows
mkdir out
javac -encoding UTF-8 -d out src/*.java

# Linux / macOS
mkdir -p out
javac -encoding UTF-8 -d out src/*.java
```

> 源码与输出包含中文，Windows 终端如出现乱码，请先执行 `chcp 65001`
> 或使用 `javac -encoding UTF-8` 并确保控制台输出编码为 UTF-8。

### 运行

```bash
java -cp out Park
```

### 在 IDEA 中运行

1. `File → Open` 选择本项目目录；
2. 确认模块 SDK 已配置为 JDK 8+；
3. 打开 `src/Park.java`，点击 `main` 方法旁的运行按钮。

## 使用说明

启动后进入主菜单循环：

```text
=========================================
===============停车场管理系统===============
=========================================
1. 进入登记 2.驶出结算 3.当前车位查询 4.收入统计 5.退出系统
```

### 示例会话

进入登记：

```text
1
请输入车牌号：
京A12345
进入登记成功
```

当前车位查询（初始 100，一辆车入场后）：

```text
3
当前车位数为：99
```

驶出结算（需输入与应收金额一致的整数以模拟支付）：

```text
2
请输入车牌号：
京A12345
停车费为：6
6
支付成功
驶出结算成功
```

收入统计：

```text
4
总收入为：6
```

> 提示：**驶出结算会自动读取一次输入作为"支付金额"**，请直接输入停车费对应的整数，
> 不要输入车牌号；输入其他数字将提示"支付失败"并保留车位占用。

## 计费规则

停车费由 `Stat.getFee()` 计算，采用**按小时计价 + 起步价**的简化模型：

```java
public static final int PRICE = 2;   // 每小时 2 元

public int getFee() {
    this.outTime = LocalDateTime.now();
    int time = this.outTime.getHour() - this.inTime.getHour();
    return (PRICE * time) + 4;       // 2 元/小时 × 时长 + 4 元固定费用
}
```

即：

```text
停车费 = 2 × (离场小时数 − 入场小时数) + 4
```

| 场景 | 计算结果 |
| :--- | :--- |
| 同一小时内进出（时长 0 小时） | 4 元（仅固定费用） |
| 停放 3 小时 | 10 元 |
| 停放 10 小时 | 24 元 |
| 跨零点停放 | 时长为负，费用可能低于固定值甚至为负 |

费率通过常量 `Stat.PRICE` 统一配置，修改该值即可整体调整单价。

## 核心类设计

### `Park` — 业务主类

| 成员 | 类型 | 说明 |
| :--- | :--- | :--- |
| `stallCount` | `static int` | 车位总数，默认 100 |
| `stats` | `HashMap<String, Stat>` | 在场车辆，键为车牌号 |
| `income` | `List<Fee>` | 已完成结算的收入流水 |

| 方法 | 输入 | 输出 | 说明 |
| :--- | :--- | :--- | :--- |
| `enter(String code)` | 车牌号 | `1` 成功 / `-1` 失败 | 未登记或状态为"已出"时登记入场，车位 −1 |
| `exit(String code)` | 车牌号 | `1` 成功 / `-1` 失败 | 计算费用并读取支付金额，支付成功则记录收入、车位 +1 |
| `query()` | 无 | 打印剩余车位 | 超出 0–100 范围时提示系统错误 |
| `sumFee()` | 无 | 打印总收入 | 遍历 `income` 累加 |
| `main(String[] args)` | 无 | 无 | 菜单循环与输入分发 |

### `Stat` — 车辆停放状态

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `code` | `String` | 车牌号 |
| `inTime` | `LocalDateTime` | 入场时间 |
| `outTime` | `LocalDateTime` | 出场时间（计费时写入） |
| `state` | `int` | 进出状态，`1` 表示在场，`0` 表示已离场 |
| `feeState` | `int` | 费用状态，`0` 未支付，`1` 已支付 |
| `PRICE` | `static final int` | 小时单价，默认 2 元 |

方法：`getFee()` 计算费用、`getState()/setState()` 读写进出状态、
`getFeeState()/setFeeState()` 读写支付状态、`setOutTime()` 设置出场时间。

### `Fee` — 收入记录

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `code` | `String` | 车牌号 |
| `fee` | `int` | 本笔停车费 |

方法：`getCode()`、`getFee()`。该类为不可变的简单值对象（字段公开，通过构造函数注入）。

## 数据结构

```text
Park
 ├── stallCount : 100                ← 全局剩余车位
 ├── stats : HashMap<车牌, Stat>      ← 快速判断车辆是否在场
 │      "京A12345" → Stat(code, inTime, state=1, feeState=0)
 └── income : ArrayList<Fee>          ← 按结算顺序追加的收入流水
        [ Fee("京A12345", 6), Fee("沪B88888", 4), ... ]
```

- 使用 `HashMap` 以车牌为键，使进场去重与结算查找均为 O(1) 平均复杂度。
- 使用 `ArrayList` 顺序保存收入，`sumFee()` 线性遍历累加，为 O(n)。

## 已知限制

本项目定位为教学演示，以下限制是刻意保留的简化，也提醒使用者注意其影响：

1. **数据不持久化**：所有状态保存在内存中，程序退出即丢失。
2. **未校验车位是否已满**：`enter()` 未在 `stallCount == 0` 时拒绝入场，可能出现负数车位。
3. **按时钟小时差计费**：使用 `getHour()` 之差而非真实时长，
   45 分钟会算作 1 小时，跨零点（如 23:00 入场、次日 01:00 离场）结果不正确。
4. **支付为本地模拟**：没有真实支付渠道，仅比对输入整数与应收金额。
5. **输入未做异常防护**：`scanner.nextInt()` 遇到非数字输入会抛出异常。
6. **车牌未做格式校验**：任意非空白字符串都可作为车牌登记。
7. **单机单线程**：未考虑并发访问与多人同时操作同一车位池。
